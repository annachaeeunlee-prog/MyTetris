# Stardrop

A cosmic falling-block puzzle game — single HTML file, no build step.

**Play:** https://annachaeeunlee-prog.github.io/MyTetris/

- ☄ **Comets** occasionally fall and blast a crater where they land.
- ✦ **Supernova** charges as you clear lines — press **E** to vaporize the bottom four rows.
- Every 10 lines warps you to a new sector: faster drops, new nebula colors.

Controls: ← → move · ↑/X rotate · Z rotate back · ↓ soft drop · Space hard drop · C hold · E supernova · P pause · M mute. Touch buttons appear on phones.
